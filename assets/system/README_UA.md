# ShiftTime Builder — системна бібліотека ассетів

Ці файли лежать у проєкті, тому їдуть разом із ZIP/флешкою/Netlify.

## Як додавати нові файли
1. Розпакуй ZIP.
2. Поклади нові файли у:
   - assets/system/incoming/backgrounds
   - assets/system/incoming/images
   - assets/system/incoming/logos
   - assets/system/incoming/icons
3. Скинь ZIP на аналіз.
4. Після аналізу файли будуть перенесені в тематичні папки, а описи/теги/оцінки будуть додані в assets/system/manifest.json.

## Важливо
Галерея показує проєктні системні файли тільки якщо вони описані в assets/system/manifest.json.
Один файл може лежати в одній папці, але мати багато themes/tags/themeScores і показуватись у різних фільтрах.
